### How personalization works

Subscribers can add up to **3 keywords** such as `diffusion models`, `protein folding`, or `CRISPR`. The daily pipeline searches Semantic Scholar for those keywords first. Selected domains (CS, Physics, Biology, or Math) provide fallback candidates and context so the digest stays aligned with the subscriber's interests.

Each daily email includes **up to 3 papers**, with at most one paper from each curation lane:

| Lane | What it surfaces |
| --- | --- |
| **New in your field** | A recent paper that matches the subscriber's keywords or selected domains. |
| **Heating up** | A recent paper gaining attention, weighted by quality signals and relevance. |
| **Adjacent Insight** | A related paper from the selected domains that broadens the subscriber's view without drifting into unrelated filler. |

Daily curation order:
1. Load active subscribers and collect unique keywords, capped at 3 per subscriber.
2. Search each unique keyword once, with rate-limit backoff.
3. Fetch fallback and context papers from selected domains.
4. Score candidates by paper quality, keyword match, domain fit, and recency.
5. Select up to one qualifying paper for each lane, summarize only the unique selected papers, and send the digest.

If no qualifying papers are fresh or relevant enough for a subscriber, everymorning sends a **no-fresh-papers email** instead of filling the digest with irrelevant papers.
